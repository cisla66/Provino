**Correzione (Linux):** una nuova versione aperta da Scaricati viene sempre spostata nella cartella delle applicazioni.

---

## Provino 1.1.3 (English)

- **Linux.** If Provino is already installed and you open a new AppImage from Downloads, Provino always offers to move it to the applications folder (`~/Applications`), even when the old file is gone. Before, in that case the menu entry was silently linked to the file in Downloads, and deleting it broke the entry.
- **Linux.** The in-app update always puts the new version in the applications folder.
- Mac: no changes.

---

## Provino 1.1.3 (Italiano)

- **Linux.** Se Provino è già installato e apri una nuova AppImage da Scaricati, Provino propone sempre di spostarla nella cartella delle applicazioni (`~/Applicazioni`), anche quando il file vecchio non c'è più. Prima, in quel caso, la voce nel menu veniva collegata in silenzio al file in Scaricati, e cancellandolo la voce smetteva di funzionare.
- **Linux.** L'aggiornamento dentro Provino mette sempre la nuova versione nella cartella delle applicazioni.
- Mac: nessuna modifica.
