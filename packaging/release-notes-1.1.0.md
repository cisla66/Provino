## Provino 1.1 (English)

- **A color for each day.** The line above the photos and the date label change color with every shooting day, so you see at once where an outing starts and ends.
- **Select › By date…** Tick the days you need (say Saturday and Sunday) and Provino picks all their photos. Active filters still apply: with "RAF" on, it takes only the RAFs.
- **One folder per event.** In the Download window, "One folder for the event" starts the name with the first day's date (`2026_10_30_`): just add the event name. Spaces become `_` and characters not allowed in folder names are removed. JPG/RAF subfolders still work inside the event. Photos in event folders are recognised as already downloaded.
- **Show all.** From the progress ring, the full list of files being downloaded, with thumbnail and status; the current file always stays in the middle, so after an interruption you see right away where it stopped.

**Downloads**
- Mac (macOS 11 or later, Intel and Apple Silicon): `Provino-1.1.0-mac.dmg`. Not signed by Apple: the first time, use System Settings › Privacy & Security › "Open Anyway".
- Linux (GNOME): `Provino-1.1.0-x86_64.AppImage`.

Provino 1.0 users get this update offered at launch, or via "Check for Updates…".

## Provino 1.1 (Italiano)

- **Un colore per ogni giornata.** La linea sopra le foto e l'etichetta con la data cambiano colore a ogni giorno di scatto: vedi subito dove inizia e dove finisce un'uscita.
- **Seleziona › Per data…** Spunti i giorni che ti servono (per esempio sabato e domenica) e Provino sceglie tutte le loro foto, rispettando i filtri attivi.
- **Una cartella per l'evento.** Nella finestra Scarica, «Una cartella per l'evento» parte dalla data del primo giorno (`2026_10_30_`): aggiungi solo il nome. Gli spazi diventano `_` e i caratteri non ammessi nei nomi delle cartelle spariscono. Le sottocartelle JPG/RAF restano possibili dentro l'evento. Le foto nelle cartelle evento sono riconosciute come già scaricate.
- **Mostra tutti.** Dall'anello dell'avanzamento, l'elenco di tutti i file in scaricamento con miniatura e stato; il file in corso resta sempre al centro.

**Download**
- Mac (macOS 11 o successivo, Intel e Apple Silicon): `Provino-1.1.0-mac.dmg`. Non firmata da Apple: al primo avvio usa Impostazioni di Sistema › Privacy e sicurezza › «Apri comunque».
- Linux (GNOME): `Provino-1.1.0-x86_64.AppImage`.

Chi ha Provino 1.0 riceve la proposta di aggiornamento all'avvio, oppure da «Cerca aggiornamenti…».
