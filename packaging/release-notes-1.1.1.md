**Fix:** downloading into an event folder you already have no longer creates a second folder inside it.
**Correzione:** scaricando in una cartella evento che hai già, Provino non crea più un'altra cartella dentro.

---

## Provino 1.1.1 (English)

- Pick an existing event folder (its name starts with `YYYY_MM_DD_`) with "Choose…" in the Download window: Provino turns off "One folder per shooting day" and "One folder for the event" by itself and downloads right inside it, into its JPG and RAF subfolders if "Split by type" is on.
- If you turn one of those options back on, an orange warning tells you a new folder would be created inside the event.

Useful when an event spans several cards or days: add the photos from the second card to the folder you already have.

---

## Provino 1.1.1 (Italiano)

- Scegli con «Cambia…» una cartella evento che hai già (il nome inizia con `AAAA_MM_GG_`): Provino toglie da solo «Una cartella per ogni giorno di scatto» e «Una cartella per l'evento» e scarica direttamente lì dentro, nelle sottocartelle JPG e RAF se «Separa per tipo» è attivo.
- Se rimetti una di quelle spunte, un avviso arancione ti dice che verrebbe creata una cartella nuova dentro l'evento.

Utile quando un evento occupa più schede o più giorni: aggiungi le foto della seconda scheda alla cartella che hai già.
